Featured Project: Education Management System

The Education Management System is a database-driven application for managing a school or college. It stores student records, teacher details, courses, attendance and exam results in an SQL database, and gives administrators a simple interface to add, search, update and report on this data.

The screens were first designed in Figma, and the web interface is built with semantic HTML and CSS. The business logic is written in Python, with SQL handling all data storage.

Role: Developer and UI designer. Tools: Python, SQL, HTML5, CSS3, Figma.
